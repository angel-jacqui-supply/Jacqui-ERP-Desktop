# Jacqui ERP pour ordinateur

Installateurs officiels et mises à jour signées de Jacqui ERP pour macOS, Windows et Linux.

Téléchargements et aide : https://erp.jacqui.supply/#telecharger

- Mac : installateur DMG universel pour Apple Silicon et Intel.
- Windows : installateur EXE 64 bits ; MSI disponible dans les releases.
- Linux : AppImage 64 bits ; DEB et RPM disponibles dans les releases.

Connectez-vous avec votre compte Jacqui habituel. Internet est nécessaire pour se connecter et enregistrer les modifications. Les fiches déjà consultées peuvent être relues hors connexion.

Les mises à jour sont signées et proposées dans l’application. Le compte et les réglages sont conservés lors des mises à jour.

Ce dépôt contient uniquement les fichiers de distribution, leurs signatures et les manifestes de mise à jour. Le code source est privé. La signature des mises à jour est distincte des certificats Apple et Windows.
